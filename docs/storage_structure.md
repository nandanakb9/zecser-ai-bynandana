# AI Storage Structure

## Resume Storage
data/resumes/
- Original uploaded resumes (PDF/DOCX)

## Parsed Resume Storage
data/processed_resumes/
- Cleaned text extracted from resumes

## Job Description Storage
data/job_descriptions/
- Original JD files

## Parsed JD Storage
data/processed_jd/
- Structured JD JSON files

## ATS Score Storage
data/ats_scores/
- Resume vs JD matching scores

## Screening Reports
data/screening_reports/
- AI screening decisions

## Interview Results
data/interview_results/
- Interview scoring outputs
