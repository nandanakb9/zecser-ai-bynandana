# ATS Technical Documentation

## Overview

Zecpath AI Hiring System is an automated Applicant Tracking System that parses resumes, extracts structured data, scores candidates, and ranks them based on job requirements.

## Components

* Resume Parser
* Skill Extractor
* Education Parser
* Experience Parser
* Ranking Engine
* Fairness Module
* API Layer

## Workflow

Resume Upload → Parsing → Feature Extraction → Scoring → Ranking → Shortlisting

## Technologies Used

* Python
* Flask
* TF-IDF
* JSON-based pipeline
* Rule-based NLP
