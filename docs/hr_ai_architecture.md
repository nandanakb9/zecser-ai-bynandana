# HR Interview AI – Architecture Document

## System Overview
The HR Interview AI system automates candidate evaluation using ATS scoring, HR screening, interview analysis, and unified hiring intelligence.

## Architecture Flow

Resume → ATS Matching → Eligibility Engine → HR Screening →  
Transcript Storage → STT Cleaning → Answer Understanding →  
HR Scoring → Unified Scoring → Optimization → Ethics Review

## Core Modules
- ATS Matching Engine
- Eligibility Decision Engine
- HR Screening Dataset
- Transcript Data Architecture
- STT Cleaning Module
- Answer Understanding Engine
- HR Scoring Engine
- Unified Scoring Engine
- Optimization Engine
- Ethics & Compliance Layer

## Data Flow
1. Resume parsed and matched with job description
2. Candidate eligibility determined
3. HR screening questions generated
4. Voice responses converted to transcript
5. Transcript cleaned and normalized
6. Answers interpreted into structured format
7. Scores calculated across rounds
8. Unified hiring score generated
9. Ethics and fairness checks applied

## Output
- Candidate HR Score
- Hiring Fit Percentage
- AI Interview Summary
- Compliance Report
